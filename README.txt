This folder has ONE file that matters: index.html (everything is inside it - video, photos, all pages).
Includes: Built & Bold (muted red/black alternating), Expect Nothing. Appreciate Everything., Forged on the Field,
Team Rentals | Lane Bookings with The Forge + Public Pitching Lane + Training + Services,
original KBuilt logo in header, KB square app icon, smaller homepage quote in Barlow grey.
Cart + Team Rentals form save to the visitor browser (localStorage) - no server needed.

DEPLOY - pick ONE (no build, no npm, no folder upload):
1) Netlify Drop (easiest): go to app.netlify.com/drop, drag index.html onto the page. Done.
2) Cloudflare Pages: Pages -> Upload assets -> drag index.html.
3) GitHub Pages single file: create a repo, Add file -> Upload files, upload ONLY index.html, then Settings -> Pages -> Source: Deploy from a branch, Branch: main, Folder: / (root). Wait 1-2 min.
4) Any host (GoDaddy, Bluehost, etc.): upload index.html to public_html / www.

You do NOT need to upload a folder. One file is the whole site.
